# automobile-image-forgery-review
This project develops an AI-assisted review workflow for automobile photographs submitted before an insurance claim is filed. The system does not make a final decision on whether an image is authentic or forged. Instead, it combines multiple forgery hints and presents them in an interpretable report for human review.

The python scripts are divided into the copy move, image quality, metadata analysis and the SAFIRE model to create a manipulation map. Since SAFIRE required a GPU, that code is included in a Google Colab notebook, for which I have attached the file separately.
